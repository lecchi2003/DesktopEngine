DataGrid

Tabelas de dados avançadas com suporte nativo a filtros, ordenação e paginação. Tudo reativo ao instance.state.

Paginação Client-Side (Padrão)

A paginação no DataGrid é incrivelmente simples. Basta fornecer a propriedade itemsPerPage com o número desejado de linhas por página. Neste modo, o framework espera que o array referenciado em bindData contenha todos os registros. A tabela se encarrega de fatiar os dados (slice) e desenhar a barra de navegação no rodapé.

Exemplo Interativo

import { DataGrid, Badge } from './ui.js';

const gridEl = DataGrid({
    bindData: "clientes", // Nome do array no instance.state
    instance: this,       // Referência da Tela
    itemsPerPage: 3,      // <--- Ativa a paginação a cada 3 itens
    columns: [
        { key: "id", label: "Código", sortable: true },
        { key: "nome", label: "Cliente", filterable: true },
        { 
            key: "status", 
            label: "Situação", 
            render: (val) => Badge({ text: val, variant: "success" }) 
        }
    ]
});

Paginação Server-Side

Quando você está lidando com uma base de dados enorme (ex: milhares de clientes), baixar todo o Array para fazer a paginação client-side vai travar o navegador. Nesses casos, utilizamos a Paginação Server-Side.

Atenção: No padrão Server-Side, o servidor já devolve os dados fatiados, a página atual e o total de itens. O DataGrid serve apenas como casca visual.

Como implementar a arquitetura Server-Side no DesktopEngine:

1. Adapte o estado (State)

Ao invés de guardar um grande Array, seu estado guardará a página atual e os total de itens apenas daquela página:

state: {
    clientes: [], // Só conterá os clientes da página atual
    paginaAtual: 1,
    totalPaginas: 10
}

2. Configure o Componente DataGrid

Ative a opção serverSide, defina qual variável contém o total de páginas com bindTotalPages, e defina uma onPageChange action para buscar a nova página.

DataGrid({ 
    bindData: "clientes", 
    instance: ctx.instance,
    serverSide: true, // Desativa a paginação client-side
    bindTotalPages: "totalPaginas", // Variável de estado com o total de páginas
    onPageChange: "buscarPagina" // Dispara essa action ao trocar de página
});

3. Crie a Action que vai na API

Na configuração da sua Tela, você programa a ação para disparar o Fetch e atualizar o grid:

actions: {
    buscarPagina: [async (ctx, novaPagina) => {
        ctx.instance.setStatus("Carregando página " + novaPagina);
        
        // Vai no banco de dados buscar a nova página
        const response = await fetch(`/api/clientes?page=\${novaPagina}`);
        const data = await response.json();
        
        // Atualiza a tabela na tela
        ctx.state.clientes = data.items;
        ctx.state.totalPaginas = data.totalPages;
        ctx.instance.update();
    }]
}
