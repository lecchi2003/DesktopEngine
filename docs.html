Desktop Engine V0.6 - Documentação Oficial

Um micro-framework focado em sistemas corporativos de Janela Única/Múltipla (Desktop in Browser) utilizando apenas Vanilla JS e ES Modules, sem passos de build.

Executando o Projeto (Módulos ES)

Como o projeto utiliza import/export nativo do navegador, ele não rodará corretamente se você abrir o index.html via protocolo file:/// no Windows/Chrome.

Dica Rápida: Basta clicar duas vezes em server.bat na pasta do projeto. Ele iniciará um servidor Python na porta 8000. Depois, acesse http://localhost:8000 no seu navegador.

Inicialização do Desktop

O desktop agora suporta configurações de inicialização para posicionar o "Taskbar" em qualquer canto da tela e ligar/desligar botões de utilidade.

import { Desktop } from './desktop.js';

Desktop.init({
    windowsContainerId: "windows",
    taskbarContainerId: "taskWindows",
    taskbarPosition: "bottom", // Aceita: "top", "bottom", "left", "right"
    showDesktopButton: true    // Mostra/oculta o botão de minimizar tudo
});
  • Desktop.showDesktop(): Minimiza todas as janelas ativas ou as restaura.
  • Desktop.arrangeWindows(): Organiza todas as janelas abertas numa "Grade" simétrica na tela.

Criando Telas (Windows)

O motor é baseado na criação declarativa de telas através de objetos JavaScript simples, com estado reativo gerenciado por Proxies.

import { Framework } from './core.js';
import { Desktop } from './desktop.js';
import { Form, Input, Button, createElement } from './ui.js';

const MinhaTela = {
    title: "Minha Primeira Tela",
    icon: "🚀",
    width: 400,
    height: 300,
    singleInstance: true,
    
    // Estado inicial (O motor torna-o reativo)
    state: { nome: "" },
    
    // Actions (Middlewares assíncronos)
    actions: {
        salvar: [async (ctx, next) => {
            alert(\`Salvando \${ctx.state.nome}\`);
            ctx.instance.setStatus("Salvo com sucesso!");
        }]
    },
    
    // View (Retorna elementos DOM)
    view() {
        return createElement("div", "", [
            Input({ label: "Nome", bind: "nome", instance: this }),
            Button({ text: "Salvar", onClick: "salvar", instance: this })
        ]);
    }
};

// Abrindo a tela no Desktop
Desktop.open(Framework.createWindow(MinhaTela, "ID_UNICO", Desktop));

Usando Middlewares nas Actions

A grande vantagem do actions é o suporte a uma esteira de middlewares no estilo Koa/Express. Isso é perfeito para validações e controle de acesso.

// Middleware Desacoplado
export const ValidateForm = (fields) => async (ctx, next) => {
    for (let field of fields) {
        if (!ctx.state[field]) {
            Desktop.notify(\`O campo \${field} é obrigatório!\`, "warning");
            return; // Interrompe a esteira
        }
    }
    await next(); // Passa no teste
};

// Uso na tela:
actions: {
    salvar: [
        ValidateForm(['nome', 'email']), // 1. Valida
        async (ctx) => {
            // 2. Só executa se a validação passar
            api.post('/users', ctx.state);
        }
    ]
}

Catálogo de Componentes (ui.js)

Primitivas de Layout

  • Row({ children, style }): Cria uma linha flexível (display: flex).
  • Col({ children, style }): Cria uma coluna expansível (flex: 1).
  • Grid({ children, columns = 2 }): Um grid CSS poderoso.
  • Card({ title, children }): Caixa com sombra para agrupar informações.
  • Tabs({ tabs, activeTabBind, instance }): Sistema de abas conectado ao state.

Inputs e Controles (Two-Way Binding)

  • Input({ label, bind, instance, type }): Tipos nativos (date, text, number).
  • Select({ label, bind, instance, options })
  • Toggle({ label, bind, instance }): Switch moderno estilo iOS.

Visualização Dinâmica & DataGrid

O DataGrid é a ferramenta definitiva para tabelas. Ele suporta ordenação, filtros por coluna e Paginação nativa.

DataGrid({
    bindData: "clientes", // Nome do array no instance.state
    instance: this,
    itemsPerPage: 5,      // Ativa a paginação
    columns: [
        { key: "id", label: "Código", sortable: true },
        { key: "nome", label: "Cliente", sortable: true, filterable: true },
        { key: "status", render: (val) => Badge({ text: val }) }
    ]
})
Paginação Client-Side vs Server-Side:

Client-Side (Padrão): O DataGrid espera que a variável atrelada ao bindData no state contenha todos os registros. O componente faz um .slice() e cuida da navegação sozinho.

Server-Side: Quando você lida com bases de dados enormes, o padrão Client-Side trava o navegador. Nesses casos, siga os passos abaixo para configurar a Paginação Server-Side.

1. Adapte o estado (State)

Ao invés de guardar um grande Array, seu estado guardará apenas os itens da página atual:

state: {
    clientes: [], // Só os clientes da página atual
    paginaAtual: 1,
    totalPaginas: 10
}

2. Configure o Componente DataGrid

Ative a opção serverSide e defina onPageChange:

DataGrid({ 
    bindData: "clientes", 
    instance: ctx.instance,
    serverSide: true, 
    bindTotalPages: "totalPaginas", 
    onPageChange: "buscarPagina" 
});

3. Crie a Action que vai na API

actions: {
    buscarPagina: [async (ctx, novaPagina) => {
        ctx.instance.setStatus("Carregando página " + novaPagina);
        
        const response = await fetch(`/api/clientes?page=\${novaPagina}`);
        const data = await response.json();
        
        ctx.state.clientes = data.items;
        ctx.state.totalPaginas = data.totalPages;
        ctx.instance.update();
    }]
}

Componentes Flutuantes Globais

MenuBar vs StartMenu

O DesktopEngine suporta dois estilos globais. Escolha configurando seu index.html e invocando a UI correspondente:

  • StartMenu (Estilo Windows): Ancorado na taskbar inferior.
  • MenuBar (Estilo macOS): Fixado no topo, com menus dropdown em hover.

Menu de Contexto

Invoque localmente no seu elemento para garantir escopo, utilizando bindContextMenu:

import { bindContextMenu } from './ui.js';

bindContextMenu(meuElemento, [
    { label: "Editar", action: () => alert("Editando...") },
    { label: "Deletar", action: () => meuElemento.remove() }
]);

Impressão e Exportação

O framework fornece uma API nativa para imprimir componentes isoladamente, sem mostrar as bordas do navegador.

import { printElement } from './ui.js';

// Imprimindo apenas a tabela gerada pelo DataGrid
printElement(gridEl, { title: "Relatório Financeiro" });
